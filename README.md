# Calmavie Clinic

Production website for Calmavie Clinic in Hampton.

## Deployment

Cloudflare Workers deploys the static files in `public/` whenever the `main` branch is updated.

- Build command: none
- Deploy command: `npx wrangler deploy`
- Production domain: `https://calmavie-clinic.com`

The former Surrey Nail Artisan website remains a separate project and is not changed by this repository.
